## Миграция

- **Вход ядра** — по обязательству `core-auth`, срок 3 выпуска. Подключите `platform-auth` и `platform-rate-limit`, заведите таблицы по образцу `sql/platform-auth/create-*.sql` и перенесите в них учётные записи: хеши BCrypt переносятся как есть, доменный профиль ссылается на учётную запись. Объявите `platform.auth.roles`, `platform.auth.default-roles`, `platform.auth.link-base` и порты `AuthLetters`, `HumanCheck`, `RegistrationHook`, `ApiAccess` — реализацией либо явной заглушкой. Клиент — `provideAuth()` и `authInterceptor` из `@apocarteres/auth`. Свой вход, сессии, токены действий и ограничитель снимаются.
- **Шлагбаум перед отправкой** (`REQ-QUALITY-004`) может требовать расписку о пройденном `verify` вместо прогона `check`: `conventions attested --commit <коммит>`. Прежний вид остаётся допустимым.
- **Тесты модулей с хранилищами** требуют Docker. Без своего Docker набор ядра гоняется в сборочном контейнере: `DOCKER_CONTEXT=<машина сборки> mise run verify-runner`.
