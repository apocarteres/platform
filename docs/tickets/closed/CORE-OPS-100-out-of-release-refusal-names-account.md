# Отказ коммиту задачи вне состава молчит об учёте

## Проблема

Запись хода незавершённой задачи, задевшая соседний документ (строку
заявки ядру в runbook), — не запись по `REQ-RELEASE-040`, а работа по
задаче вне состава, и закрытие выпуска она держит. Отказ называл два выхода —
довести задачу или отменить коммит `!revert`, — оба невозможны для задачи,
ждущей решения. Законный третий выход, учёт `release account`
(`REQ-RELEASE-042`), отказ не называл, и потребитель, найдя его сам, счёл его
обходом.

## Подтверждение

Заявка потребителя [issue #57](https://github.com/apocarteres/platform/issues/57)
(clanlog, ядро 11.3.0). Сверено 2026-09-25 по `recordCommit` и
`wayIntoComposition`.

## Последствия при сохранении текущего поведения

Исполнитель перед отказом без названного выхода — ровно то, что запрещает
`REQ-RELEASE-039`.

## Решение владельца

Решение владельца от 2026-09-25: круг записей не расширять — документ вне
каталога задач может быть самой работой, — а отказ называет учёт с хешем.

## Требуется

Отказ коммиту задачи вне состава называет `release account <хеш> --reason`
для каждого её коммита.

## Критерии приёмки

- Тест первым: отказ по задаче без выпуска и по отнесённой задаче называет
  учёт с хешами своих коммитов и не называет чужих; запись с документом рядом
  держит закрытие, после учёта — не держит. Тесты падали до правки.

## Что сделано

- `wayIntoComposition` называет учёт каждого коммита задачи;
  `REQ-RELEASE-039` уточнено.
- Два теста падали до правки. 5 проб: четыре пойманы сразу; «учёт только
  первого коммита» прошла — тест дополнен вторым коммитом задачи, после этого
  поймана.
