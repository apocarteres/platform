# Отметка действия развёртывания — по номеру пункта, а не по тексту

## Проблема

`release status` при внешнем хранилище сопоставлял отметку действия с
действием по полному тексту. Хранилище держало отметки всех 11 действий
выпуска потребителя, а `release status --json` показал их неотмеченными:
текст записи хранилища шёл с переводами строк, где у ядра пробел, а часть
задач правили после закрытия выпуска. Перезакрытие в документе выпуска
сопоставляло отметку по тексту так же.

## Требуется

1. Ключ отметки — задача, шаг и номер пункта (`REQ-RELEASE-052`); текст —
   только для показа.
2. Расхождение текста записи хранилища с описанием задачи видно в
   `release status --json` полем `recorded`, отметка при этом засчитана.

## Критерии приёмки

- Отметка находится при переводе строки вместо пробела и при изменённом
  тексте — внешнее хранилище и перезакрытие документа выпуска.

## Ход работы

- 2026-11-22 — `actionsOf` (`lib/store/shape.mjs`) и `collectedActions`
  (`lib/release/deployment-actions.mjs`) сопоставляют по номеру пункта;
  тесты в `external-store.test.mjs` и `deployment-actions.test.mjs`.

## Откуда пришла задача

Заявка потребителя TR-255 через Manager: выпуск 2026.11.19 завершён прямым
`release finish`, потому что `release status` не видел отметок.
