## Миграция

Старшая версия по `REQ-PUBLISHING-004`: новое правило уровня директивы `modal-escape`. Правило молчит, пока проект не объявил признак своих модальных окон, поэтому при обновлении проверка ничьей не краснеет и действий не требует. Переход — работа по обязательству `modal-escape`: объявить `"modal": {"selector": …}` в `.conventions.json`, подключить `@apocarteres/modal`, поставить `apoModal` с `[apoModalEscape]` на каждое окно, для незакрываемых — `ESCAPE_IGNORED`, и снять собственный стек `Escape`.
