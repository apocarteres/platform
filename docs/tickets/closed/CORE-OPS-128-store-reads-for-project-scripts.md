# Чтения внешнего хранилища для скриптов проекта

## Проблема

При внешнем хранилище ([CORE-OPS-126](CORE-OPS-126-external-ticket-store.md))
чтения контракта доступны только внутри пакета правил. Скрипты проекта,
которые раньше читали файлы задач и выпусков, — развёртывание, сборка
выпуска, проверки CI — после перехода остаются без источника и вынуждены
писать свой клиент контракта.

## Подтверждение

- Команды `conventions store` печатают только адрес и итог проверки; ответа
  чтения в машинном виде нет.
- `release status` печатает текст для человека: действий развёртывания и их
  отметок в нём нет.
- Манифест тега несёт номера и заголовки задач состава, а значений полей
  проекта не несёт: сборка на коммите тега не узнаёт их без обращения к
  хранилищу.

## Последствия при сохранении текущего поведения

Каждый проект пишет свой клиент хранилища и расходится с контрактом ядра;
значение поля проекта, от которого зависит сборка выпуска, теряется молча.

## Требуется

1. Команды чтения, печатающие ответ контракта в JSON: поиск по номерам,
   рабочий набор, открытый выпуск.
2. `release status --json`: открытый выпуск, состав, действия развёртывания с
   отметками, препятствия закрытию либо завершению.
3. Значения полей проекта задач состава — в манифесте тега.

## Критерии приёмки

- Чтения печатают JSON в форме контракта и к ключу записи не обращаются.
- `release status --json` называет действия развёртывания до первого шага
  закрытия без отметок, после него — с отметками.
- Манифест тега несёт значения полей проекта задач состава.
- `mise run verify` зелёный.

## Ход работы

- 2026-11-11 — реализовано: чтения `conventions store --lookup | --working | --open`, `release status --json`, значения полей проекта в манифесте тега (`lib/store/cli.mjs`, `lib/store/shape.mjs`); требование — `REQ-STORE-023`, манифест — `REQ-STORE-011`.
- Отметок действий до первого шага закрытия контракт не даёт: действия попадают в выпуск операцией закрытия. `release status --json` до него называет действия без отметок.
- `release status --json` при файлах отказывает: состав и действия там читаются из документа выпуска.

## Вне задачи

Тело задачи в чтениях: требует добавления в контракт и согласия хранилища.
