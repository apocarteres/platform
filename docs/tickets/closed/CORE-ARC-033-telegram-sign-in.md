# На сайт нельзя войти через Telegram

## Проблема

Вход на сайт — только почта и пароль (`REQ-AUTH-005`), второй шаг — порт
`SecondFactor` без готовой реализации (`REQ-AUTH-041`). Потребители просят
вход через Telegram и код второго шага в Telegram.

## Подтверждение

Просьбы потребителей, разговор с владельцем 2026-11-16.

## Последствия при сохранении текущего поведения

Проект, которому нужен вход через Telegram, строит свой путь входа в обход
сессии и пределов ядра.

## Решение владельца

Решение владельца от 2026-11-16 — в `CORE-ARC-030`: этап 4 модуля
`platform-telegram`; вход только для учётных записей со связью, учётных
записей без почты не заводить.

## Требуется

1. Вход через Telegram Login Widget: точка входа ядра проверяет подпись
   (ключ из токена бота) и срок `auth_date` и открывает обычную сессию
   ядра (`REQ-AUTH-008`) учётной записи со связью (`CORE-ARC-030`); без
   связи — тот же отказ, что и неверный вход, без раскрытия, есть ли связь
   (`REQ-AUTH-003`).
2. Блокировка, неподтверждённая почта, пределы частоты и второй шаг — как
   у входа по паролю.
3. Готовая реализация `SecondFactor`: код в Telegram учётной записи со
   связью, короткий срок, одна попытка на код.
4. Контракт OpenAPI и клиент `@apocarteres/auth`.

## Критерии приёмки

- Подделанная и просроченная подпись — отказ; связанная учётная запись —
  сессия; заблокированная — `account-blocked`.
- Код второго шага приходит в Telegram и принимается один раз.
- `mise run verify` зелёный.

## Ход работы

- 2026-11-16 — порт ядра `SignIn` (`REQ-AUTH-048`): открытие сессии вынесено
  из контроллера входа в общий класс, и вход по паролю и вход, удостоверенный
  модулем, идут одним путём. `SecondFactor.challenge` — метод по умолчанию,
  совместимо с прежними реализациями.
- `POST /api/telegram/<бот>/login` (`REQ-TELEGRAM-020`) — по боту, с учётом
  `CORE-ARC-034`; клиент — `AuthSession.signInWith` в `@apocarteres/auth`.
- Второй шаг (`REQ-TELEGRAM-021`) — бот из
  `platform.telegram.second-factor.bot`, текст — бин проекта
  `TelegramCodeText`; требуется связанным с этим ботом записям.

## Откуда пришла задача

Разговор с владельцем 2026-11-16 о поддержке Telegram; этап 4 из 4.
