## Несовместимые изменения

- `platform-api-version` пропускает запрос без заголовка `X-Api-Version`, если у него нет признака браузера (`Sec-Fetch-Site` или `Referer`); прежде такой запрос получал `426` (`REQ-CLIENT-UPDATE-006`). Проверка ослабевает: запросы с заголовком и браузерные запросы без него сверяются, как прежде.

## Миграция

Правок не требуется. Машинные пути из `platform.api.version-exempt-paths` можно убрать: вызовы без заголовка и без признака браузера проходят сами. Перечень остаётся для путей, которые нужно освободить и от браузера. `conventions static-check` предупреждает о политике `no-referrer`: на стенде по `http` она снимает последний признак браузера.
