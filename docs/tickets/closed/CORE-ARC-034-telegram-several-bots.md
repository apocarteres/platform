# Модуль Telegram знает только одного бота

## Проблема

`platform-telegram` 17.9.0 описывает бота одним набором настроек
`platform.telegram.bot-token`, `bot-name`, `webhook-secret`: у приложения
может быть только один бот. Связь, ссылка связи, webhook и доставка
уведомлений не знают, о каком боте речь.

## Подтверждение

Указание владельца 2026-11-16: приложение может использовать несколько
ботов Telegram, и модуль обязан это учитывать.

## Последствия при сохранении текущего поведения

Проект со вторым ботом пишет его связь, webhook и отправку сам, рядом с
модулем, и повторяет всё, что модуль должен был снять с проектов.

## Решение владельца

Указание владельца от 2026-11-16: несколько ботов обязательны. Форма
настроек, путей и таблиц меняется несовместимо — новая мажорная версия с
описанной миграцией (`REQ-PUBLISHING-005`).

## Требуется

1. Боты объявляются по идентификатору: `platform.telegram.bots.<бот>.*`;
   прежние ключи останавливают запуск с указанием миграции.
2. Webhook, ссылка связи и снятие связи — по боту; связь — пара
   «учётная запись, бот».
3. Каждый бот — свой канал доставки уведомлений; текст по боту даёт проект.
4. Клиент видит связи со всеми ботами одним запросом.

## Критерии приёмки

- Два бота в одной службе: связи, webhook и доставка не путаются.
- Токен связи одного бота другим ботом не принимается.
- `mise run verify` зелёный.

## Ход работы

- 2026-11-16 — настройки `platform.telegram.bots.<бот>.token`, `.name`,
  `.webhook-secret`; прежние ключи останавливают запуск со ссылкой на
  миграцию. Пути `/api/telegram/<бот>/webhook`, `/api/telegram/<бот>/link`,
  связи всех ботов — `GET /api/telegram/links`.
- Таблицы: связь и ссылка — по паре «учётная запись, бот»; уникальность
  человека и чата — внутри бота. Набор `platform-telegram:003-bots` относит
  строки 17.9.0 к боту `main`.
- Java API: `TelegramBots.bot(<бот>)`, `TelegramLinks.chat(account, bot)`,
  `TelegramReplies.linked(bot, language)`, `TelegramNotice.bot()`; каналы
  уведомлений `telegram-<бот>`.
- Клиент: `TelegramLink.bots`, `linked`, `invite(bot)`, `unlink(bot)`.
