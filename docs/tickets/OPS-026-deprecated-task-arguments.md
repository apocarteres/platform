# Задача менеджера окружения объявляет аргументы устаревшим способом

## Проблема

Задача `release-open` в `mise.toml` передаёт аргументы шаблонными функциями
`{{arg(name="version")}}` и `{{arg(name="tickets")}}`. Менеджер окружения
объявил эти функции устаревшими и убирает их в версии 2027.5.0, предлагая
взамен поле `usage`.

Пока задача работает, но каждый её запуск печатает предупреждение, а после
удаления функций задача перестанет работать вовсе — то есть перестанет
открываться выпуск, потому что открытие требует перечня задач
(`REQ-RELEASE-007`) и других входов у него нет.

## Чем подтверждено

Прогон 2026-09-10 при открытии выпуска 1.3.0, `mise` 2026.6.14:

```
mise WARN deprecated [tera_template_task_args]: Task 'release-open' uses
deprecated Tera template functions (arg(), option(), flag()) in run scripts.
Use the 'usage' field instead. This will be removed in mise 2027.5.0.
```

Замена проверена на отдельной задаче-пробе: аргументы объявляются полем
`usage`, а в команде читаются переменными окружения `$usage_<имя>`.

```
[tasks.probe]
usage = 'arg "<version>"\narg "<tickets>"'
run = 'echo "версия=$usage_version задачи=$usage_tickets"'

$ mise run probe 1.4.0 OPS-001,OPS-002
версия=1.4.0 задачи=OPS-001,OPS-002
```

Предупреждения при таком объявлении нет.

## Последствия при сохранении текущего поведения

1. Открытие выпуска перестанет работать при обновлении менеджера окружения, и
   узнается это в момент, когда выпуск нужно открыть.
2. Предупреждение печатается при каждом запуске и приучает не читать вывод
   задач.
3. Версия менеджера окружения закреплена (`REQ-BUILD-004`), поэтому обновление
   произойдёт намеренно и вместе с ним понадобится эта правка — лучше сделать
   её заранее, чем в один момент с обновлением.

## Ожидаемый результат

Задачи объявляют аргументы полем `usage` и читают их переменными окружения.
Устаревших шаблонных функций в `mise.toml` не остаётся.

## Критерии приёмки

- `mise run release-open <версия> <задачи>` работает и предупреждения не
  печатает.
- Шаблонных функций `arg()`, `option()`, `flag()` в `mise.toml` нет.
- Описание задачи по-прежнему называет порядок аргументов.

## Откуда пришла задача

Наблюдение при открытии выпуска 1.3.0: команда сработала, но напечатала
предупреждение об устаревшем способе объявления аргументов.
