# Пакет процессных правил и инструментов документации

## Цель

Опубликовать npm-пакет `@apocarteres/project-conventions`: CLI с проверками документации и генераторами сводок плюс тексты правил (`RULES.md` задач и выпусков, `TEMPLATE.md`, общий фрагмент `AGENTS.md`, единый документ требований к UI). Оба проекта и сам репозиторий `platform` становятся его потребителями.

## Основание

1. В zavpn и clanlog одна идея правил реализована двумя несовместимыми форматами и двумя наборами скриптов: 1274 строки Node с тестами против 730 строк Python и Node без тестов ([ADR-0001](../decisions/ADR-0001-shared-core.md), раздел 2.3).
2. Требования к модалкам были скопированы из clanlog в zavpn и разошлись: из общего текста осталось четыре совпадающие строки.
3. Инструментарий в этом репозитории уже перенесён из zavpn (`scripts/docs`) с двумя правками: терпимость к отсутствующим каталогам и обязательный раздел «Почему не делаем» у отменённой задачи. Пока это копия, а не пакет.

## Последствия при сохранении текущего поведения

Каждое улучшение правил делается дважды и проверяется по-разному; расхождения обнаруживаются только при чтении глазами.

## Требуется

1. Параметризовать `check-docs.mjs`: перечень обязательных целей каталога, имена индексных файлов и расположение задач читаются из конфигурации проекта, а не из констант.
2. Оформить CLI с командами `check`, `tickets-index`, `releases-index`, `file-sizes`, `toolchain-pins`, `money-types`, `config-secrets` (последние четыре переносятся из `clanlog/scripts/ops`) и `sync`.
3. Команда `sync` вписывает тексты правил в проект между маркерами `<!-- conventions:begin -->` и `<!-- conventions:end -->`; `check` отказывает при ручной правке внутри маркеров и при отставании версии пакета.
4. Reusable GitHub workflow (`workflow_call`) с job `docs`, `secrets`, `backend`, `frontend`; проектные job остаются в проектах.
5. Миграция clanlog: ~110 тикетов переводятся скриптом с bold-строк на front matter, статусы отображаются `открыт → backlog`, `частично выполнено → in_progress`, `отложено → blocked`, `выполнено → done`, `отменено → cancelled`; каталоги по областям сворачиваются в поле `scope`.

## Критерии приёмки

- `mise run docs-check` в `platform`, zavpn и clanlog вызывает CLI пакета одной и той же версии.
- Тесты инструментов переезжают в пакет и проходят в его CI.
- Ручная правка внутри маркеров в любом из трёх репозиториев приводит к отказу `check`.
- После миграции clanlog его `docs-check` проходит, а число тикетов и их статусы совпадают с состоянием до миграции.

## Границы

Правило о комментариях и минимальный CLI (`check`, `sync`, `baseline`) выделены в [TICKET-CODE-COMMENTS-RULE](code-comments-rule.md): они не зависят от вопросов ниже. Здесь остаётся перенос остальных общих правил, миграция формата тикетов clanlog, reusable workflow и переносимые храповики.

3. Приоритет при противоречии общего фрагмента `AGENTS.md` и проектной части. Рекомендация: общий фрагмент задаёт минимум; проект может ужесточить правило снаружи маркеров, но не ослабить. Зависит: пункт 3 требований. Ответ: —
