# Выпуск по шагам: задача выпуска, заморозка и e2e отдельными командами

## Проблема

Хранилище ведёт выпуск задачей выпуска и шагами — открытие с задачей,
заморозка, зелёный e2e на коммите, закрытие только этого коммита. Пакет
правил открывал выпуск без задачи и закрывал одной командой, где отказ
проверки снимал заморозку. Потребитель с внешним хранилищем не мог вести
выпуск по шагам, не обращаясь к API хранилища в обход ядра.

## Требуется

1. `release open --task`, `release freeze`, `release unfreeze --reason`,
   `release record-e2e --commit` (`REQ-STORE-026`).
2. `release close` закрывает замороженный выпуск без повторной заморозки и
   проверяет e2e на коммите до тега.
3. `release status --json` показывает `task` и `e2e`.

## Критерии приёмки

- Тест: выпуск с задачей, заморозка, отказ закрытия без e2e и с e2e на
  другом коммите — выпуск остаётся замороженным, тега нет; запись e2e на
  коммите — закрытие проходит.
- Тест: разморозка с причиной и без неё.
- При файлах задач новые команды отказывают и называют выход.

## Ход работы

- 2026-11-22 — команды в `lib/store/cli.mjs` и `bin/conventions.mjs`,
  `freezeRelease` и сверка e2e в `lib/store/cycle.mjs`, форма в
  `lib/store/check.mjs`; проект изменений — ADR-0010.
