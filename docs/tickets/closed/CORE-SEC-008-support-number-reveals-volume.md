# Номер обращения выдаёт число обращений

## Проблема

Номер обращения — порядковый столбец `GENERATED ALWAYS AS IDENTITY`. Автор
видит его в ответе приёма, письмах и кабинете.

## Подтверждение

Потребитель ядра (2026-10-24): обращение на стенде получило номер «№4».

## Последствия при сохранении текущего поведения

Любой, кто подаст два обращения с промежутком, узнаёт, сколько обращений
принял проект и как быстро они приходят, — внутреннее состояние проекта.

## Ожидаемый результат

1. Номер нового обращения — случайные восемь цифр (10000000–99999999),
   уникальный; совпавший выбирается заново.
2. Тип номера в API, письмах и колокольчике не меняется — целое число.
3. Номера, выданные раньше, остаются.

## Критерии приёмки

1. Два обращения подряд получают восьмизначные номера, не идущие подряд.
2. Совпадение номера не роняет приём.
