# Человек не видит своих сессий

## Проблема

Ядро ведёт индекс сессий по учётной записи и умеет завершать их все
(`Sessions.terminate`), но человеку ни список, ни завершение одной сессии не
отдаёт. Где открыта учётная запись, он не знает.

## Подтверждение

Потребитель ядра (2026-10-25) строит профиль клиента: блок «Сессии» со
списком и завершением одной или всех прочих.

## Последствия при сохранении текущего поведения

Украденную сессию человек не обнаружит и закроет только сменой пароля,
которая выбрасывает и его собственные сессии.

## Ожидаемый результат

1. При входе в сессию записываются адрес сети и браузер.
2. `GET /api/auth/sessions` — свои сессии: вход, последнее обращение, адрес,
   браузер, признак текущей; идентификатор — отпечаток, не значение сессии.
3. `DELETE /api/auth/sessions/{id}` — завершить одну, `DELETE
   /api/auth/sessions` — все, кроме текущей; чужую завершить нельзя.
4. Клиент `@apocarteres/auth`, контракт OpenAPI и `REQ-AUTH`.

## Критерии приёмки

1. Список не содержит значений сессий.
2. Завершённая сессия отвечает 401 на следующем запросе; чужой отпечаток
   ничего не завершает.
