# Потребитель не может открыть своим потребителям тот же канал заявок

## Проблема

Канал заявок есть только в одну сторону — от потребителя к ядру. У него
названный адрес, форма с обязательными разделами, срок ответа и запрет
комментировать закрытые заявки (`REQ-ADOPTION-019`, `REQ-ADOPTION-020`,
`REQ-ADOPTION-025`). У потребителя, у которого свои потребители, ничего
этого нет: ни объявления адреса, ни формы. Каждый проект, решивший принимать
заявки, переписывает шаблон ядра руками, и формы расходятся.

## Подтверждение

Решение владельца от 2026-10-06: потребитель объявляет, как его потребители
сообщают ему, тем же механизмом, что и ядро.

## Последствия при сохранении текущего поведения

Заявка между потребителями приходит в произвольной форме: без версии, без
того, чем подтверждено, без срока ответа. Разбор начинается с переписки,
от которой ядро избавилось для своих заявок.

## Решение владельца

Решение владельца от 2026-10-06:

- канал обязателен только тому, кто его объявил: ядро не знает, есть ли у
  проекта свои потребители;
- ядро даёт шаблон заявки командой; правила проверки шаблона и адреса в
  отказах команд проекта не нужно.

## Требуется

1. Положение `REQ-ADOPTION-027`: адрес — ключ `feedback.url` в
   `.conventions.json`, шаблон — команда `conventions feedback-template`,
   форма та же, что у заявки в ядро, срок ответа и запрет комментариев —
   те же.
2. Команда пишет `.github/ISSUE_TEMPLATE/consumer-report.md` с именем проекта
   из адреса. Без адреса — отказ, называющий ключ. Шаблон, изменённый руками,
   не перезаписывается.
3. Инструкция `RUN-CONSUMER-FEEDBACK` описывает путь для проекта со своими
   потребителями.

## Критерии приёмки

- Тест первым: без `feedback.url` команда отказывает и называет ключ; адрес
  не https — отказ; объявленный канал получает шаблон с именем и версией
  проекта, сроком ответа и запретом комментариев; разделы шаблона совпадают
  с разделами заявки в ядро; повтор ничего не меняет, изменённый руками
  шаблон не перезаписывается.
- Пробы: убранный раздел формы, снятый запрет комментариев, перезапись
  чужого шаблона — тесты падают.

## Откуда пришла задача
