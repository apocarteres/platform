# Время прогона e2e — общим пакетом, а не копией в каждом проекте

## Проблема

Два проекта-потребителя пишут время каждого теста и шага e2e одной записью
формата 1 и держат для этого свои копии репортёра Playwright и сборщика
записи. Копии уже разошлись (каталог файла теста, число потоков, отправка в
приём наблюдения есть только у одной), и каждая правка формата делается
дважды.

## Требуется

1. Пакет `@apocarteres/e2e-timing`: репортёр Playwright (`/reporter`) и
   сборщик `e2e-timing collect` — запись формата 1, история стенда, сводка,
   отправка в приём наблюдения (`REQ-E2E-TIMING`).
2. Подготовка стенда в записи — выкатка того же коммита из файла проекта либо
   фазы подъёма стека; стек проекта (Ansible и прочее) пакет не знает.
3. Сбой записи и отправки прогон не роняет.

## Критерии приёмки

- Модульные тесты пакета: часть прогона, запись, история, сводка, отправка,
  разбор аргументов.
- Потребитель подключает репортёр и сборщик из архива пакета и удаляет свои
  копии (работа потребителя после выпуска ядра).

## Ход работы

- 2026-11-21 — пакет `packages/e2e-timing` (`lib/reporter.mjs`,
  `lib/record.mjs`, `lib/send.mjs`, `lib/cli.mjs`, `bin/e2e-timing.mjs`),
  требование `REQ-E2E-TIMING`, тесты `node --test`. Черновик — слот Driada-Lab
  (патч к ядру по заявке Manager), принят в ядро с правками.
- 2026-11-21 — правки при приёме: `--workers` вне целого больше нуля —
  ошибка аргументов (код 2), а не `null` в записи; знак отличия в сводке
  одним символом; ссылка комментария — на положение.
