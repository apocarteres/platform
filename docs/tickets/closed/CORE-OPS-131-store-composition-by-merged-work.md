# Состав выпуска при внешнем хранилище ждёт «выполнена», которую ставит сам выпуск

## Проблема

У потребителя слияние PR задачу больше не закрывает: «выполнена» ставит
выход выпуска. Ядро же при внешнем хранилище подбирало в состав только
выполненные задачи без выпуска, а закрытие и завершающий шаг отказывали,
пока в составе есть невыполненная. Задача на проверке со слитой работой в
выпуск не попадала, и выпуск, который должен был её закрыть, её не видел.

## Требуется

1. Состав при внешнем хранилище подбирает задачи без выпуска, которые
   выполнены либо названы коммитом диапазона закрытия, в любом статусе,
   кроме отменённой и замещённой; снятая задача подбором не возвращается.
2. Закрытие не требует «выполнена»: держит только указанная при открытии
   задача без слитой работы. Завершающий шаг статусы не проверяет.
3. Обязательство закрывается задачей состава, которая не отменена.

## Критерии приёмки

- Задача «на проверке» со слитой работой — в составе; отменённая — нет;
  выпуск закрывается и завершается, задачи состава становятся выполненными
  (эталонное хранилище тестов).
- Указанная при открытии задача без слитой работы держит закрытие.

## Ход работы

- 2026-11-19 — `REQ-STORE-024`, `compositionOf`, `ships` и `mergedNames` (без `!revert`, с порогом `commitRuleSince`; поля проекта — как у `done`) в

  `withdrawn` в `lib/release/documents.mjs`; эталонное хранилище тестов
  ставит «выполнена» при `finishRelease`. Цикл с файлами задач не менялся.
