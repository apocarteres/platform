# Правила ядра не видят девяти его модулей

## Проблема

Проверка правил ядра читает каталоги из поля `sources` файла
`.conventions.json`. Список составлен вручную и остался таким, каким был при
первом пакете клиента: в нём три модуля Java и `packages/http`. Модули и
пакеты, появившиеся позже, в него не попали:

- `platform-api-version`, `platform-arch-rules`, `platform-auth`,
  `platform-rate-limit`;
- `packages/action`, `packages/app-update`, `packages/auth`,
  `packages/modal`, `packages/routing`.

Ядро требует от потребителя правил, которые к этим девяти модулям не
применяет само. Пропуск молчаливый: зелёная проверка выглядит одинаково и
когда нарушений нет, и когда проверка каталога не читает (`REQ-QUALITY-014`).

## Подтверждение

Найдено 2026-09-24 при заведении пакета `@apocarteres/client-journal`
(CORE-ARC-016). Проба: `Date.now()` в `packages/auth/src` при прежнем списке
проходит проверку, при полном — отказ `REQ-CODE-CLOCK`.

## Последствия при сохранении текущего поведения

Каждый новый модуль ядра выходит без проверки правил, пока кто-то не заметит
список; нарушение в нём находит потребитель, а не ядро.

## Требуется

1. `sources` перечисляет каталог `src` каждого модуля `platform-*` и каждого
   пакета `packages/*`.
2. Тест пакета правил отказывает, если модуль или пакет ядра в `sources`
   не перечислен, и называет его.
3. Имена, ставшие видимыми, фиксируются ограничителем, как существующие
   (`REQ-JAVA-NAMING-006`).

## Критерии приёмки

- Проверка правил проходит на полном списке.
- Тест падает, если из списка убрать один каталог.

## Что сделано

- В `sources` добавлены девять каталогов. Нарушений правил-директив нет.
- Проявились 8 имён на `-er` — рекомендация, проверку не роняет:
  `RateLimiter`, `RedisRateLimiter` и имена в тестах (`Letter`, `Browser`,
  `Player`, образцы `Upper`, `Lower`, `LeftSideHolder`). Они существовали до
  находки, поэтому зафиксированы ограничителем явно (`baseline
  --allow-growth`), а не переименованы: `RateLimiter` — открытый API ядра.
- Тест `core-sources.test.mjs`; проба — убран `packages/auth/src`, тест
  упал и назвал его.
