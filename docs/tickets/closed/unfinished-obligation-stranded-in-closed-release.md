# Невыполненное обязательство оставалось в закрытом выпуске

## Проблема

Обязательство ядра планируется в выпуск при его открытии, и его задача
получает идентификатор этого выпуска. Если к закрытию работа не сделана,
задача оставалась назначенной в уже закрытый выпуск, в состав которого
она не вошла.

## Подтверждение

После закрытия первого выпуска zavpn `docs-check` дал ошибку:
`docs/tickets/reduce-comment-ratchet-2026-09-07.md: задача отсутствует
в составе назначенного выпуска`. Обязательство `comment-ratchet-to-zero`
со сроком в шесть выпусков законно не сделано, а его задача указывала
на закрытый выпуск.

## Последствия при сохранении текущего поведения

Обязательный набор проверок падает после каждого закрытия выпуска, в котором
осталось незакрытое обязательство — то есть в норме. Срок обязательства
при этом теряет смысл: перенос был возможен только правкой руками.

## Ожидаемый результат

Открытие следующего выпуска переносит в него задачи незакрытых обязательств
и объявляет их строкой состава с причиной «перенесено из предыдущего
выпуска». Вторая заготовка не создаётся.

## Критерии приёмки

- [x] Требование [REQ-RELEASE-021](../../requirements/release-cycle.md#REQ-RELEASE-021) описывает перенос запланированного, но не выполненного обязательства
- [x] Открытие выпуска переназначает задачу обязательства и добавляет строку состава — `lib/release/cycle.mjs`, `openNext`
- [x] Тест: после закрытия выпуска задача переехала в новый выпуск, заготовка не продублирована — 71 тест пакета проходит
