# Установка ядра собирает клиентские пакеты столько раз, сколько их

## Проблема

`scripts/install-local.sh` вызывал `scripts/web.sh build` в `pack_package`
для каждого пакета со сборкой, а `web.sh build` собирает все пакеты сразу:
при девяти пакетах — 81 сборка вместо 9. Установка ядра шла около 500 с при
45 с на Maven.

## Подтверждение

Заявка потребителя [issue #58](https://github.com/apocarteres/platform/issues/58)
(zavpn, ядро 11.3.0), журнал раската рабочей среды 2026-09-25. Сверено
2026-09-25 по `install-local.sh`; то же видно в журнале выпуска ядра 11.4.0.

## Последствия при сохранении текущего поведения

Раскат потребителя, ставящего ядро из исходников, длится почти десять минут, и
время растёт квадратом числа пакетов.

## Решение владельца

Решение владельца от 2026-09-25: сборка один раз до перебора пакетов, перебор
только пакует.

## Требуется

Одна сборка за установку, если сборка нужна хотя бы одному публикуемому
пакету; пакет со сборкой пакуется из собранного, без сборки — из исходника.

## Критерии приёмки

- Тест первым: установка во временном дереве с заглушками `mvnw` и `web.sh`
  вызывает сборку один раз и пакует каждый публикуемый пакет. Тест падал до
  правки (две сборки на два пакета).

## Что сделано

- `install-local.sh`: сборка до перебора, `pack_package` только пакует.
- `core-install-local.test.mjs`. 4 пробы: две пойманы сразу; «пакует исходник
  вместо собранного» и «собирает ради непубликуемого» прошли — тест дополнен
  проверкой содержимого архива и случаем непубликуемого пакета, после этого
  пойманы обе.
