## Несовместимые изменения

- Модальное окно `apcrModal`, внутри которого идёт `apcrAction`, на время вызова поглощает `Escape` без вызова `[apcrModalEscape]`: прежде обработчик вызывался всегда.
- Щелчок по кнопке `apcrLocal` внутри окна во время вызова до обработчика проекта не доходит.

## Миграция

Поведение `apcrModal` и `apcrAction` меняется само и правок кода не требует. Новое правило `modal-backdrop` действует для проекта, объявившего `modal.backdrop`: фон объявляется директивой `apcrModalBackdrop` с обработчиком либо `BACKDROP_IGNORED`, собственный `(click)` с фона снимается. Отказ удалённого действия показывается внутри окна. Работа — по обязательству `modal-busy-backdrop`.
