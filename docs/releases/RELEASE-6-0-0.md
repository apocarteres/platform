## Миграция

- **Открытые вопросы.** Если задач с `questions: open` больше 9, ответьте на вопросы и поставьте `questions: resolved` либо задайте свои пороги в `.conventions.json`: `release.openQuestions` с полями `remind` и `require`. Больше 4 — только напоминание.
- **Развёртывание без простоя** — выбор проекта, правок не требует. Выбравший объявляет `deployment.withoutDowntime` с каталогом `migrations`, при желании `expandReleases` (по умолчанию 2) и `instances`. После этого действует правило `migration-labels`: первая строка каждого перехода — `-- migration: additive | expand | contract <переход> | breaking`; `expand` без парного `contract` — долг со сроком. Порядок развёртывания печатает `conventions migrations --unreleased`, активный экземпляр записывает `conventions manifest --instance <имя>`.
- **Замок фоновых работ** — `JdbcJobLock` из `platform-persistence`, таблица по образцу `sql/platform-job-lock/create-table.sql`, переходом `additive`.
