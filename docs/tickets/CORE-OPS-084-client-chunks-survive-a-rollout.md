# Куски клиента переживают раскат, их размер держит проверка

## Проблема

Клиент собирается кусками с отпечатком содержимого в имени. Раскат стирает
куски прежней сборки, и вкладка, открытая до него, не может открыть раздел с
отложенной загрузкой, пока её не перезагрузят. Правка одной строки меняет
отпечаток у десятков файлов, поэтому ломается любая открытая вкладка. Хранить
прежние куски в раздаваемом каталоге нельзя: `conventions deployed` сверяет
сумму всего дерева (`REQ-DEPLOYMENT-016`), и лишний файл даёт расхождение.

Бюджеты размера кусков видит только сборка Angular, а превышение порога
предупреждения её не роняет.

## Решение владельца

Решение владельца от 2026-09-24: принять четыре пункта ниже; прежние куски
хранятся 7 дней по умолчанию, и проект задаёт свой срок настройкой — как длиннее, так и короче.

## Требуется

1. **Архив прежних кусков** (директива). Раздаваемый каталог — точная копия
   сборки; прежние куски лежат в архиве вне его, и сверка развёрнутого архива
   не видит. Файл, которого нет в текущей сборке, ищется в архиве;
   `index.html` из архива не отдаётся. Кусок хранится в архиве 7 дней с
   момента, как перестал раздаваться, либо столько, сколько задал проект
   настройкой: срок можно и удлинить, и сократить.
   Откат пополняет архив так же, как раскат.
2. **Кэширование** (директива). Вечный кэш (`immutable`) — только файлам с
   отпечатком в имени; `index.html` — `no-store`; отказ из архива — без
   вечного кэша.
3. **Проверка стенда** — команда вида `conventions static-check --url <стенд>`
   после раската: кусок прежней сборки отвечает 200, выдуманный файл — 404
   без `immutable`, `index.html` не из архива. Образец настройки nginx —
   рекомендацией (`REQ-ADOPTION-021`).
4. **Бюджеты под проверкой ядра**: в `angular.json` допустим только порог
   ошибки, порог предупреждения — отказ `check`.
5. **Отложенная загрузка с обработкой отказа**: правило находит `@defer` без
   `@error`, по образцу правил модальных окон. Отказ `loadComponent`
   обрабатывает механизм обновления клиента (CORE-ARC-011).

## Открытые вопросы

1. Может ли проект задать срок хранения короче 7 дней, или его настройка
   только удлиняет срок? Ответ: может и сократить — решение владельца от
   2026-09-24.
