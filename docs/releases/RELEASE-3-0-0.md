## Несовместимые изменения

- Префикс директив ядра сменился с `apo` на `apcr`: `apoModal` → `apcrModal`, `apoModalEscape` → `apcrModalEscape`, класс `ApoModal` → `ApcrModal`. Шаблоны с прежними именами перестают собираться; прежних имён рядом не оставлено.

## Миграция

Заменить в шаблонах и импортах `apoModal` на `apcrModal` и `ApoModal` на `ApcrModal` — поведение не менялось. Новое правило `modal-actions` действует для проекта, объявившего признак окон: каждая кнопка окна объявляет `apcrAction` (удалённое действие из `@apocarteres/action`) или `apcrLocal` (местное). Окна, закрывающиеся до ответа сервера, переводятся на `apcrAction` с закрытием по `(apcrActionDone)` — работа по обязательству `modal-actions`.
