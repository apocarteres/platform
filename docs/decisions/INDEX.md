# Архитектурные решения

Решение получает стабильный идентификатор `ADR-NNNN`, состояние `proposed`, `accepted`, `rejected` или `superseded` и ссылки на затронутые требования и задачи. После принятия обязательные инварианты переносятся в требования; решение не становится параллельным источником нормы.

## Принятые решения

- [ADR-0002: контракты слоя persistence](ADR-0002-persistence-contracts.md) — запросы в файлах, тип вместо исключения для условной записи, своя сериализация команд, необязательный Jackson.
- [ADR-0003: локальная публикация артефактов](ADR-0003-local-artifact-publishing.md) — GitHub как хранилище репозитория, артефакты в локальный репозиторий Maven и архивом npm, проверки локально.
- [ADR-0004: поведение модалок — контракт и код](ADR-0004-ui-behaviour-contract.md) — общий контракт поведения, атрибутные директивы без шаблонов, ловушка фокуса из CDK, намерение закрытия вместо закрытия.
- [ADR-0005: кнопка, ждущая удалённого вызова](ADR-0005-async-action-button.md) — состояние ожидания ведёт ядро, директива без разметки, отказ доходит до обработчика.
- [ADR-0006: здоровье и метрики как контракт ядра](ADR-0006-health-and-metrics.md) — Micrometer, отдача встроенным контроллером, запрет меток с идентификаторами, порт здоровья со сроком, живость против готовности.
