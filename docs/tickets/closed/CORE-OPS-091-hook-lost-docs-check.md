# Шлагбаум перед отправкой перестал проверять документы, принятая идея не проходила проверку

## Проблема

Первая принятая идея ядра (`CORE-IDEA-001`) ушла в `main` с деревом, которое
`docs-check` отвергает: поле `ticket` у принятой идеи проверка документов
считала неизвестным. Тесты идей проверяли модуль отдельно и через полную
проверку документов принятую идею не прогоняли.

Уйти в `main` это смогло потому, что хук второго вида (CORE-OPS-088) требовал
только расписку на дерево кода, а прежний хук гонял `check` вместе с
`docs-check`. Документы вне дерева кода — расписка их не покрывает.

## Что сделано

- Поле `ticket` допустимо только у идеи; у задачи и прочих документов — отказ.
- Хук `pre-push` после расписок прогоняет `docs-check`; `REQ-QUALITY-004`
  уточнено.

## Чем закреплено

Тест полной проверки документов с принятой идеей и с задачей, несущей
`ticket`; проба «поле у идеи не пропускается» роняет его.
