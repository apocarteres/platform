# Публичный репозиторий ядра без лицензии

## Проблема

Репозиторий публичен, но лицензии нет: код виден, а права его использовать
никто не получил. Пакеты npm клиента помечены MIT, пакет правил —
`UNLICENSED`, в POM лицензии нет.

## Подтверждение

2026-10-15: `gh repo view` — `visibility: PUBLIC`, `licenseInfo: null`;
файла `LICENSE` нет; `grep license packages/*/package.json` — MIT и
`UNLICENSED`; `<licenses>` нет ни в одном POM.

## Последствия при сохранении текущего поведения

Открыть проект нельзя: без лицензии действует «все права защищены», а
расхождение лицензий пакетов вводит в заблуждение.

## Решение владельца

Решение владельца от 2026-10-15: Apache-2.0 (ADR-0008).

## Требуется

`LICENSE`, `NOTICE`, `<licenses>` и `<scm>` в родительском POM,
`<licenses>` в `platform-bom` без родителя, `license: Apache-2.0` в каждом
`package.json` и в корневой записи `package-lock.json`.

## Критерии приёмки

- Тест первым: лицензия на месте во всех названных файлах.
- Проба: пакет с прежней лицензией — тест падает.

## Откуда пришла задача

Решение владельца открыть проект, 2026-10-15.
