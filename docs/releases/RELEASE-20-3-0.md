# Выпуск 20.3.0

Правила выпуска — `REQ-RELEASE` в поставке пакета правил. [Каталог](INDEX.md)

## Цель

Выпустить состояние сервиса, накопленное после предыдущего выпуска, и исполнить обязательства ядра, попавшие в этот выпуск.

## Для хранилища

Выпуск минорный, контракт остаётся третьим (`REQ-STORE-027`, `ADR-0011`).

- `release freeze` теперь отказывает там, где позже отказало бы закрытие. Чтобы заморозка не пропускала этапы, которые держат внешний исполнитель или владелец, хранилище помечает такие условия `before-release` полем `due: "freeze"`.
- Перенос e2e через правки вне сборки работает при двух условиях. Хранилище отдаёт `task` и `e2e` у открытого выпуска (20.2.0) и принимает необязательный `from` в `recordE2e`. Проект объявляет пути вне сборки в `e2e.outsideBuild`.
