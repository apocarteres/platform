# У развёртывания нет общего интерфейса

## Проблема

Проекты, подключившие ядро, разворачиваются каждый по-своему — не в глубине, а
уже на входе:

```
zavpn:   mise run deploy -- --env qa --only backend
clanlog: scripts/deploy-production.sh --host root@metrics
```

Разные входы, разные ключи, разные умолчания. Третий потребитель придумает
третий. Человек, перешедший между проектами, каждый раз читает справку заново, а
ядро не может ни предложить шага, ни проверить порядок: оно не знает, из чего
проект состоит.

## Решение владельца 2026-09-21

Ядро владеет интерфейсом развёртывания, а не его машинерией. Из обязательного —
имя среды; всё прочее по умолчанию: разворачиваются все составляющие, какие у
проекта есть.

Перечень составляющих объявляет сам проект: у одного это Java и Angular, у
другого Java, Angular и Rust.

## Что сделано

`REQ-DEPLOYMENT-015`: единственный вход, обязателен один довод — имя среды, всё
прочее по умолчанию. Разворачиваются все объявленные составляющие; ключ выбора
остаётся, но он сужение умолчания, а не обязанность.

Проект объявляет составляющие и среды разделом `deployment` в
`.conventions.json` — там же, где объявляет ядру прочее:

```json
{"deployment": {
  "environments": ["local", "qa", "prod"],
  "components": {"backend": {"artifact": "backend/target/app.jar"}}}}
```

Каждая составляющая называет артефакт — тот самый путь, появление которого
утверждает её шаг сборки. Так объявление и `REQ-BUILD-013` держатся вместе, а
не порознь.

Команда `conventions components` отдаёт перечень построчно, чтобы скрипт
развёртывания спрашивал его, а не держал вторым местом. Довод тот же, что с
версиями инструментов: перечень в двух местах расходится.

## Граница, ради которой это сделано

Ядро перечня составляющих не задаёт и задавать не может — он принадлежит
предметной области: у одного проекта сервер и клиент, у другого ещё и агент.
Ядро задаёт **то, как о нём спрашивают**.

Это и есть решение владельца о границе: ядро владеет интерфейсом развёртывания,
потребитель — содержимым.

## Чем закреплено

Шесть проверок. Две стоят отдельно: перечень из двух составляющих проходит
наравне с перечнем из трёх — ядро длины не диктует; необъявленное развёртывание
отличается от неверно объявленного — молчание не ошибка, проект мог ещё не
объявить.

Различающая сила проверена снятием обязательности артефакта: упали две
проверки.
