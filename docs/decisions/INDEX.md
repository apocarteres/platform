# Архитектурные решения

Решение получает стабильный идентификатор `ADR-NNNN`, состояние `proposed`, `accepted`, `rejected` или `superseded` и ссылки на затронутые требования и задачи. После принятия обязательные инварианты переносятся в требования; решение не становится параллельным источником нормы.

## Принятые решения

- [ADR-0002: контракты слоя persistence](ADR-0002-persistence-contracts.md) — запросы в файлах, тип вместо исключения для условной записи, своя сериализация команд, необязательный Jackson.

## Предлагаемые решения

- [ADR-0001: выделение общего ядра](ADR-0001-shared-core.md) — форма ядра, состав пакетов, принятые решения и открытые вопросы.
