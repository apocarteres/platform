# Подключение ядра сняло границу вокруг каталога запросов

## Проблема

Пока каталог SQL жил в проекте потребителя, границу вокруг него держала
модульная модель: каталог был именованным интерфейсом модуля, и зависимость от
него объявлялась явно. После переноса каталога в ядро эта граница исчезла:
пакет ядра для модульной проверки внешний, а внешние пакеты доступны любому
классу проекта — включая контроллер.

Ядро забрало общий код и вместе с ним сняло ограничение, о котором никто не
просил.

## Чем подтверждено

Проект-потребитель `clanlog`, архитектурный набор, правило «Каталогом SQL
пользуются только DAO». Причина записана в самом правиле:

> до перехода на общее ядро это правило держал Spring Modulith: каталог SQL был
> именованным интерфейсом, и модуль объявлял зависимость от него явно. Пакет
> ядра для Modulith внешний и потому разрешён всем, поэтому границу держит это
> правило

Потребитель восстановил границу сам, задачей `CL-DATA-015`. Заявки в ядро по
этому поводу не было: потеря выглядела как особенность своего проекта.

## Последствия при сохранении текущего поведения

Каждый следующий потребитель теряет ту же границу при подключении ядра и либо
пишет своё правило, либо не замечает потери. Второе вероятнее: до подключения
ядра ограничение работало само, и его исчезновение ничем не сообщается.
`REQ-PERSISTENCE-020` теперь требует эту границу, но требование без проверки
исполняется на слово.

## Ожидаемый результат

Проверка, отказывающая при обращении к каталогу запросов вне слоя доступа к
данным, поставляется ядром или называется потребителю готовой — так же, как
проверка модульности (`CORE-OPS-036`). Опора — объявленный проектом перечень
типов слоя доступа, а не суффикс имени (`REQ-PERSISTENCE-019`).

## Критерии приёмки

- Проверка отказывает на обращении к каталогу из контроллера и из прикладного
  сервиса.
- Проверка опирается на объявление проекта, а не на имя класса; переименование
  её не обходит.
- Потребителям сообщено заявкой, что граница восстановлена ядром и своё правило
  можно снять.

## Откуда пришла задача

Разбор решений потребителей по модульности 2026-09-12: правило `clanlog` прямо
называет причиной подключение ядра.
