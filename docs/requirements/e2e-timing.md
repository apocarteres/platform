# Время прогона e2e

[Карта требований](../REQUIREMENTS.md)

**Область действия: проект, который гоняет e2e на Playwright и подключил пакет `@apocarteres/e2e-timing`.** Пакет даёт репортёр Playwright и сборщик записи прогона одного формата, чтобы время тестов, шагов и подготовки стенда сравнивалось между прогонами и проектами. Основание — заявка потребителя: два проекта держали одинаковые копии репортёра и сборщика, и каждая правка формата делалась дважды.

**Уровень требования: директива** для пакета; подключение пакета — решение проекта.

## Часть прогона

1. <a id="REQ-E2E-TIMING-001"></a> **REQ-E2E-TIMING-001** — Репортёр пишет часть прогона в файл, названный опцией `file` или переменной `E2E_TIMING_PART`; без файла не пишет ничего. Часть — начало, длительность и итог запуска Playwright и тесты: файл от каталога сценариев проекта (`testDir`), название без проекта и файла, проект, длительность, попытки, итог, шаги `test.step` с вложенными через `›`. Повтор теста — та же запись: длительности попыток складываются, итог и шаги — последней попытки.

## Запись прогона

2. <a id="REQ-E2E-TIMING-002"></a> **REQ-E2E-TIMING-002** — Сборщик (`e2e-timing collect`) собирает части в одну строку JSON формата 1: `format`, `repository`, `commit`, `branch`, `runner`, `machine`, `stand`, `workers`, `started`, `duration`, `status`, `tests`, `steps`, `deploy`. В записи только имена спеков, тестов, шагов и фаз и времена — без данных тестов, адресов и учётных записей. Метки `runner` и `machine` берутся из `E2E_RUNNER` и `E2E_MACHINE`; метка, не похожая на короткое имя, остаётся пустой строкой. `workers` — целое больше нуля либо `null`; другое значение — ошибка аргументов.
3. <a id="REQ-E2E-TIMING-003"></a> **REQ-E2E-TIMING-003** — Подготовка стенда в `deploy` — либо выкатка из файла `--deploy`, если в нём тот же коммит, что у прогона, либо фазы подъёма стека из файла `--phases` (строки «название<TAB>секунды») без задач. Выкатка другого коммита в запись не попадает.
4. <a id="REQ-E2E-TIMING-004"></a> **REQ-E2E-TIMING-004** — Полный прогон (`--full`) дописывается в историю стенда `<--history-dir>/<стенд>/e2e-timing.jsonl` (последние 50) и отправляется в приём наблюдения; неполный — только файл `--out` и сводка. Сводка называет длительность, подготовку стенда, самые долгие тесты и шаги и отличие от прошлого полного прогона на этом стенде. Каталог истории выбирает проект, вне git.

## Отправка

5. <a id="REQ-E2E-TIMING-005"></a> **REQ-E2E-TIMING-005** — Адрес приёма — `E2E_TIMING_URL`: только `https`, `http` — только на localhost; ключ — из файла `E2E_TIMING_TOKEN_FILE` заголовком `Authorization: Bearer`, сам ключ в переменных и аргументах не передаётся. Без адреса запись остаётся в файлах.
6. <a id="REQ-E2E-TIMING-006"></a> **REQ-E2E-TIMING-006** — Сбой записи, истории или отправки прогон не роняет: сборщик выходит с кодом 0 и сообщением. Код 2 — только ошибка аргументов вызова.
