# Выпуск с задачей у проекта без e2e

## Проблема

Выпуск с задачей (`REQ-STORE-026`) закрывается только на коммите с зелёным
e2e, а хранилище отказывает `closeRelease` без него. Проект без QA-стенда
e2e не гоняет, а его инструменты выпуска требуют задачу выпуска, — выпуститься
он не мог вовсе.

## Требуется

1. Объявление проекта `e2e.required: false` с причиной (`REQ-STORE-028`).
2. `release open --task` передаёт `e2eRequired: false` и причину; шлагбаум
   закрытия не требует e2e у такого выпуска.

## Критерии приёмки

- Тест: выпуск с задачей у проекта без e2e открывается с `e2eRequired: false`
  и закрывается без записи e2e; манифест несёт поле.
- Тест: объявление без причины или вместе с `outsideBuild` — отказ открытия;
  без объявления e2e по-прежнему требуется.

## Ход работы

- 2026-11-24 — `e2eDeclaration` в `lib/store/e2e.mjs`, передача при открытии
  в `lib/store/cycle.mjs`, форма в `lib/store/check.mjs`.

Заявка потребителя DRIAD-830 через Manager (магазин без QA-стенда).
