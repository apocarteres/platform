# Задача обязательства, названная при открытии, входит в состав дважды

## Проблема

`release open <задачи>` с задачей, несущей поле `obligation`, записывал её в
состав двумя строками — «указана при открытии выпуска» и «обязательство
ядра, перенесено», — и `docs-check` отвергал открытый выпуск.

## Подтверждение

Заявка потребителя [issue #52](https://github.com/apocarteres/platform/issues/52)
(clanlog). Сверено 2026-09-25: `openNext` складывал названные и перенесённые
задачи без проверки повтора.

## Последствия при сохранении текущего поведения

Потребитель правит документ выпуска руками.

## Требуется

Задача входит в состав одной строкой — с причиной обязательства.

## Критерии приёмки

- Тест: задача обязательства названа при открытии — одна строка.

## Что сделано

- Названная задача, уже перенесённая как обязательство, не пишется второй
  строкой.
- Тест открытия; проба без исправления его роняет.

## Откуда пришла задача

[issue #52](https://github.com/apocarteres/platform/issues/52).
