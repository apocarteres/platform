# Версия API требуется от всех запросов: забытое исключение кладёт машинных клиентов

## Проблема

`REQ-CLIENT-UPDATE-006` отказывал `426` любому запросу без заголовка
`X-Api-Version`, а машинные вызовы проект перечислял в
`platform.api.version-exempt-paths`. Ошибки настройки несимметричны: забытое
исключение кладёт агентов и интеграции на производственной среде, забытая
проверка браузера лишь оставляет устаревшую вкладку без предупреждения.
Умолчание выбирало тяжёлую сторону. Путь к тому же не различает вызывающих:
один и тот же путь администратора зовут и браузер с сессией, и служебный
скрипт с токеном. Правило `client-update` полноты перечня не видит.

## Решение владельца

Решение владельца от 2026-09-24: версия требуется только у запроса браузера.
Признак браузера — заголовок `Sec-Fetch-Site`, а где его нет (адрес не по
`https` и не `localhost`, старый браузер) — `Referer`. Запрос без заголовка
версии и без признака браузера проходит. Выпуск — старшая версия: объявленное
поведение меняется, хотя проверка только ослабевает.

## Требуется

1. Запрос с заголовком версии сверяется, как прежде, от кого бы ни пришёл.
2. Запрос без заголовка отказывает, только если несёт признак браузера.
3. `platform.api.version-exempt-paths` остаётся; в требовании назван синтаксис
   шаблонов — `PathPattern` Spring MVC.
4. Тестом закреплено, что точки `actuator` проверкой не охвачены.

## Что сделано

- Перехватчик `platform-api-version`: запрос без заголовка и без признака
  браузера пропускается; заголовок, если есть, сверяется у любого вызывающего.
- `REQ-CLIENT-UPDATE-006` переписано: признак браузера, направление ошибки,
  синтаксис шаблонов исключений, `actuator` вне проверки. Формулировка
  обязательства `client-update` поправлена.

## Чем закреплено

- Тесты: браузер без заголовка по `Sec-Fetch-Site` и по `Referer` —
  отказ; машинный клиент без заголовка, в том числе с токеном, — проходит;
  машинный клиент с устаревшей версией — отказ; освобождённый путь проходит и
  у браузера; `actuator` не проверяется.
- Пробы намеренной поломкой: пять из шести роняют тест. Проба «проверять любой
  обработчик» не различается: точки `actuator` через перехватчики реестра не
  идут вовсе, и ветка «только методы контроллера» тестом не держится — её
  охват сводится к статике и предзапросам CORS.
