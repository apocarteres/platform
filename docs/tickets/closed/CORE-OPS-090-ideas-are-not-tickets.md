# Идеи с вопросами держали выпуск наравне с задачами

## Проблема

Порог открытых вопросов (`REQ-RELEASE-047`) держит выпуск, когда задач с
`questions: open` больше девяти. Потребитель пожаловался, что выпуск держат
задачи, которые на деле — идеи: у них естественно есть вопросы, и работой они
ещё не стали. Отдельного места для идей не было, и модель задач не отличала
мысль от работы.

## Решение владельца

Решение владельца от 2026-09-24: порог остаётся как есть; идея — отдельный вид
документа, её вопросы не считаются. Без приоритета и без напоминаний о
давних идеях.

## Что сделано

- Вид документа `type: idea` в `docs/ideas/`, имя `<префикс>-IDEA-<NNN>-<слаг>.md`,
  сводка `docs/ideas/INDEX.md` собирается `mise run tickets-index`.
- Проверка документов: у идеи нет приоритета, выпуска и обязательства;
  состояния `open`, `accepted`, `rejected`; принятая называет существующую
  задачу полем `ticket`, отклонённая — причину; с открытыми вопросами идея не
  принимается и не отклоняется.
- Сверка коммитов: коммит с идентификатором идеи — запись об идее, пока он
  меняет лишь `docs/ideas/`; иначе он не называет задачу.
- `release status` называет число открытых идей.
- Положения `REQ-TICKETS-017…020`, уточнение `REQ-RELEASE-047`.

## Чем закреплено

Тесты проверки документа, имени, сводки, сверки коммитов и порога при
двенадцати идеях с открытыми вопросами; десять проб намеренной поломкой,
каждая роняет тест.

## Откуда пришла задача

Жалоба потребителя, переданная владельцем 2026-09-24.
