# Обязательство сослалось на правило, которого у потребителя нет

## Проблема

Обязательство `data-access`, объявленное в 1.9.0, ссылалось на
`REQ-PERSISTENCE-017`. Документ `persistence.md` объявлен внутренним документом
ядра и потребителю не доставляется, а `REQ-ADOPTION-016` говорит прямо: текста,
которого нет в поставке, потребитель исполнять не обязан.

То есть ядро предъявило долг, исполнить который формально нечем: задача
материализуется, срок идёт, а правило прочитать негде.

## Чем подтверждено

Сообщение потребителя 2026-09-12 при разборе выпуска 1.10.0: «java-modules
исполнить можно — документ доставлен; data-access формально исполнить нечем».
Проверено по перечню доставки: `persistence.md` числится внутренним с причиной
«контракт кода самого ядра: каталог запросов, загрузчик, порты».

Ошибка моя: шесть положений о доступе к данным были дописаны в документ, не
предназначенный потребителю, и обязательство повесили на одно из них.

## Что сделано

1. Положения о доступе к данным вынесены в отдельный доставляемый документ
   `data-access.md` (`REQ-DATA-ACCESS-001`…`006`): запрет ORM, один оператор в
   методе DAO, транзакция в прикладном слое, роль объявляется проектом, каталог
   только из слоя доступа, запрет обобщённого DAO. `persistence.md` остаётся
   внутренним и описывает контракт кода самого ядра — теперь честно.
2. Обязательство `data-access` ссылается на `REQ-DATA-ACCESS-002`.
3. Ссылки на прежние идентификаторы исправлены в правилах ядра, в готовых
   архитектурных правилах и в их тестах.
4. Появилась проверка, закрывающая весь класс: обязательство обязано ссылаться
   на положение доставляемого документа. Прежняя связка её роняет — проверено
   возвратом ссылки на `REQ-PERSISTENCE-017`.

## Критерии приёмки

- Обязательство `data-access` ссылается на доставляемый документ.
- Проверка отказывает, если обязательство ссылается на внутренний документ.
- Перечень положений документа `persistence.md` не содержит правил, обращённых
  к потребителю.

## Откуда пришла задача

Разбор выпуска 1.10.0 потребителем: обязательство предъявлено на недоставленное
правило.
