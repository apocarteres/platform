# Правило денежных величин слепо к Rust

## Проблема

`REQ-CODE-DESIGN` запрещает объявлять денежную величину двоичной плавающей
арифметикой. Правило устроено под синтаксис объявления Java — `double price` —
и вдобавок само отбрасывает всё, кроме `.java`.

В Rust объявление выглядит иначе: `price: f64`. Правило не находит ничего и
молчит — то есть ведёт себя как проверка, которой нет, но выглядит как
работающая.

## Чем подтверждено

Проба:

| исходник | находок |
|---|---|
| `pub struct Order { pub price: f64, pub total_amount: f32 }` | 0 |
| `class O { double price; }` | 1 |

## Что сделано

Правило читает синтаксис объявления Rust: поле структуры, связывание `let`,
параметр функции и передачу по ссылке. Перечень денежных имён общий: он о смысле
величины, а не о языке.

| исходник | находок |
|---|---|
| `pub price: f64` | 1 |
| `let total_amount: f32` | 1 |
| `fn charge(fee: f64)` | 1 |
| `fn apply(rate: &f64)` | 1 |
| `pub ratio: f64` | 0 |
| `pub price: i64` | 0 |
| то же в строке и в комментарии | 0 |

## Чем закреплено

Проверка на восемь случаев разбора и отдельная — что правило читает **оба**
языка, каждый своим синтаксисом: до этой задачи оно отбрасывало всё, кроме
`.java`, и на Rust молчало, выглядя при этом работающим.
