# Подстановки

Порядок работы — [RULES.md](RULES.md). Уровень — директива: левое слово в текстах
проекта не употребляется.

| Запрещено | Вместо него | Почему |
|---|---|---|
| клауза | пункт требования | Калька, у читателя нет способа догадаться о значении; владелец сообщил, что слова не понимает (`CORE-DOC-011`). |
| соседний проект | имя проекта | Общий оборот задачу найти не позволяет; проект называется по имени (`REQ-NAMING-012`). |
| храповик | ограничитель | Образ вместо термина: 56 вхождений в 21 файле и ни одного объяснения (`CORE-DOC-011`). |
| порода | род | Образ из биологии: «порода дефектов» читается как метафора, а речь о виде — `род` уже в ходу («по роду проекта»). Замечание владельца 2026-09-13. |
| узор | закономерность | Образ из ремесла: «тот же узор» не говорит, что именно повторяется. Замечание владельца 2026-09-13. |
| приманка | проба | Образ из охоты для обычного проверочного опыта: временное изменение, внесённое, чтобы увидеть, поймает ли его проверка. `Проба` в текстах ядра уже принята, `REQ-AGENT-WORK-002`. Замечание владельца 2026-09-13. |
