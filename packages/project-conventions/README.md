# @apocarteres/project-conventions

Пакет процессных правил и инструментов документации для проектов на ядре
platform. Сейчас это заглушка, опубликованная для проверки канала публикации
в GitHub Packages. Содержимое появится по задаче
`TICKET-CONVENTIONS-PACKAGE` в репозитории `apocarteres/platform`.
