## Несовместимые изменения

- Панель колокольчика — только непрочитанные (`REQ-NOTIFICATIONS-004`, `REQ-NOTIFICATIONS-005`): `GET /api/notifications` и `NotificationBell.items` больше не отдают прочитанных, `read(id)` убирает уведомление из `items`, `readAll()` опустошает список. Проект, показывающий в панели прочитанные, увидит в ней другое.

## Миграция

1. Если панель рисовала прочитанные иначе (серым, с отметкой), эта ветка больше не нужна: в `items` приходят только непрочитанные.
2. Прочитанные — на своей странице проекта через `NotificationBell.page(page, size, unread)` (`REQ-NOTIFICATIONS-009`): прочитанные и непрочитанные, число всего для переключателя страниц. Прочтение на странице — `read(id)` той же службы.
3. Своего клиента к `GET /api/notifications` сверьте с тем же: в ответе только непрочитанные.
