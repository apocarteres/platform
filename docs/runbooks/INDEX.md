# Эксплуатационные инструкции

Инструкция описывает воспроизводимую операцию над существующей системой: публикацию пакета, обновление потребителя, ротацию токена registry. ## Каталог

- [Заявка потребителя в ядро](consumer-feedback.md) — куда слать, что вложить, чем и в какой срок отвечает ядро.
- [Публикация ядра локально и подключение потребителя](local-publishing.md) — тег и workflow публикации, настройка Maven и npm у потребителя, ротация токена.
- [Внедрение статического разбора](static-analysis.md) — чего не говорят инструменты: автоправка, порядок внедрения, доля шума, версии.
- [Набор проверок в сборочном контейнере](verify-runner.md) — `verify` ядра на машине сборки, когда своего Docker нет.
