# Англоязычный читатель не может понять, на чём держится порядок

## Проблема

Открытый проект описан для внешнего читателя только README. Идеи пакета
правил — положения с номерами, наборы проверок, ограничитель, расписки,
цикл выпуска, обязательства, задачи, стек, правила для агентов, канал
заявок — изложены только в русских требованиях, а их 32 тысячи слов.

## Подтверждение

Оценка перевода от 2026-10-15: русского текста около 165 тысяч слов,
нормативного — 32,5 тысячи. Решение владельца — пока вариант A: публичная
поверхность на английском, без перевода требований.

## Последствия при сохранении текущего поведения

Англоязычный читатель видит README, но не может оценить, подходит ли ему
порядок, не переводя требования целиком.

## Решение владельца

Решение владельца от 2026-10-15: вариант A — английский обзор ключевых идей
со ссылками на положения; требования остаются на русском.

## Требуется

`docs/OVERVIEW.md` на английском: каждая опора порядка — раздел со ссылкой на
определяющее положение. Ссылки из README и `docs/INDEX.md`.

## Критерии приёмки

- Тест первым: README ведёт к обзору; в обзоре нет кириллицы; названы все
  опоры.
- Пробы: русский текст в обзоре, пропавший раздел — тест падает.

## Откуда пришла задача

Разговор с владельцем 2026-10-15 об оценке перевода.
