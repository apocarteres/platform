# ADR-0008: ядро — открытый исходный код под Apache-2.0

## Контекст

Репозиторий ядра публичен на GitHub с 2026-09-06, но без лицензии: код виден,
а право его использовать никому не дано. Клиентские пакеты npm были помечены
MIT, пакет правил — `UNLICENSED`, в POM лицензии не было. В рабочих файлах —
решениях, инструкциях, тестах, шаблоне заявки — встречались названия
проектов-потребителей. Проверка истории `trufflehog` секретов не нашла.

## Решение

Решение владельца от 2026-10-15.

1. **Лицензия — Apache-2.0** для всего репозитория: `LICENSE`, `NOTICE`,
   `<licenses>` в родительском POM и в `platform-bom`, поле `license` каждого
   пакета npm. Выбрана как у Spring Boot: явная патентная лицензия, привычна
   для библиотек Java.
2. **Названия проектов-потребителей** убраны из рабочих файлов: решения,
   инструкции, требования, тесты, шаблон заявки используют обезличенные
   имена (`shop`, «потребитель А»). Записи — задачи, документы выпусков,
   ограничитель — и история git не меняются: задача называет проект, откуда
   пришла (`REQ-NAMING-012`), а переписанная история сломала бы теги,
   к которым привязаны потребители (`REQ-ADOPTION-024`). Тест ядра держит
   границу.
3. **Liquibase 5.x под FSL-1.1-ALv2** остаётся зависимостью
   `platform-persistence`; README называет это прямо. FSL запрещает только
   продукт, конкурирующий с Liquibase, и каждая версия переходит на
   Apache-2.0 через два года.
4. **README, `SECURITY.md` и `CONTRIBUTING.md` — на английском и русском.**
   Требования, задачи и решения остаются на русском (`AGENTS.md`).
   Уязвимость сообщается закрыто, через GitHub Security Advisories.
5. Публикация не меняется (ADR-0003): артефакты собираются из тега, Maven
   Central и npm не используются.

## Последствия

- Внешний пользователь вправе использовать, менять и распространять ядро на
  условиях Apache-2.0.
- Ранние версии остаются без лицензии: Apache-2.0 действует с выпуска 15.3.0.
- Права на код подтверждает владелец; ядро это не проверяет.
