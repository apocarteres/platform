# Запрос справки открывает выпуск

## Проблема

`conventions release open --help` не печатает справку, а выполняет команду:
создаёт документ выпуска и перестраивает каталог. Запрос о том, как работает
команда, меняет состояние проекта.

Причина шире одной подкоманды. Разбор аргументов выпуска ищет в строке только
известные ключи — `--version`, `--tickets`, `--note`, `--reason`, `--ticket`, —
а всё прочее отбрасывает молча. Поэтому ни `--help`, ни опечатка в имени ключа,
ни лишний аргумент не отвергаются нигде в команде выпуска.

`REQ-RELEASE-028` требует ровно обратного, но только от расписки: она отвергает
неизвестный аргумент, файла при этом не создаёт, а `--help` печатает справку.
Требование написано для одной команды, хотя обосновано свойством всех.

## Чем подтверждено

Заявка потребителя [issue #12](https://github.com/apocarteres/platform/issues/12),
ядро 1.18.0, задача потребителя `ZAVPN-OPS-046`. Воспроизведено на эталонном
потребителе:

```
release open --help -> Открыт выпуск RELEASE-2026-09-11
новых документов выпуска: [ 'RELEASE-2026-09-11.md' ]
```

## Что делать

1. Обобщить `REQ-RELEASE-028` с расписки на все команды пакета: `--help`
   печатает справку и состояния не меняет; неизвестный аргумент отвергается с
   названием аргумента и кодом возврата 2; при отказе не создаётся ни файла.
2. Свести разбор аргументов в одно место, чтобы свойство держалось общим кодом,
   а не повторялось в каждой ветке.
3. Справка каждой подкоманды выпуска называет её ключи, а не общий перечень всех
   подкоманд.
