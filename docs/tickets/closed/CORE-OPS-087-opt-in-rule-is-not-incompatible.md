# Правило, включаемое объявлением проекта, требует старшей версии зря

## Проблема

Закрытие выпуска (`REQ-PUBLISHING-015`) считает несовместимым каждое новое
правило-директиву: оно может сделать `check` потребителя красным. Но есть
правила, которые молчат, пока проект сам их не включил объявлением в
`.conventions.json`: `migration-labels` срабатывает только при
`deployment.withoutDowntime`. У нынешних потребителей такое правило `check`
не краснит — для них это новая возможность, то есть младшая версия. Инструмент
разницы не видит и требует старшую.

В 6.0.0 это не помешало: там было и настоящее несовместимое изменение. Выпуск,
в котором окажется только такое правило, получит старшую версию без причины, и
потребитель будет искать, что у него сломается.

## Требуется

1. Правило объявляет, каким разделом `.conventions.json` оно включается.
2. Закрытие выпуска не считает такое правило несовместимым, а называет его в
   «Цене обновления» отдельной строкой: новое правило, действует только для
   объявивших этот раздел.
3. Отчёт `upgrade-report` показывает его так же.
4. Правило, у которого объявление обязательно по обязательству ядра, остаётся
   несовместимым: обязательство делает включение неизбежным.

## Критерии приёмки

- Тест первым: включаемое правило не несовместимо и названо в цене и отчёте;
  раздел читается из исходников только у объявившего правила; правило с
  разделом, обязательным по обязательству, не объявляет `enabledBy`. Тесты
  падали до правки.

## Что сделано

- `REQ-PUBLISHING-015` уточнено.
- Правило объявляет раздел полем `enabledBy` (`migration-labels` —
  `deployment.withoutDowntime`); обязательство называет обязательный раздел
  полем `declares` (`backups`).
- `surface.mjs` читает `enabledBy`; `changes.mjs` не считает такое правило
  несовместимым и пишет строку «Включается объявлением».
- Тесты в `upgrade-report.test.mjs`. 5 проб: четыре пойманы сразу; «раздел
  соседнего правила» прошла — порядок правил в тесте изменён так, что чужой
  раздел перетёк бы, после этого поймана.

## Решение владельца

Заведено по согласию владельца от 2026-09-24.

## Откуда пришла задача

Наблюдение при выпуске 6.0.0: `migration-labels` потребовало бы старшей версии
само по себе.
