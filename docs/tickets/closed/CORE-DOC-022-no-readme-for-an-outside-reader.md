# Внешнему читателю не с чего начать

## Проблема

README — двенадцать строк на русском для того, кто уже знает ядро. Нет
порядка сообщения об уязвимости: единственный канал — публичная заявка, и
уязвимость была бы раскрыта до исправления. Нет описания, как участвовать.

## Подтверждение

2026-10-15: в корне нет `SECURITY.md` и `CONTRIBUTING.md`; README не говорит,
как получить артефакты и под какой они лицензией.

## Последствия при сохранении текущего поведения

Внешний пользователь не узнает, как подключить ядро, а сообщение об
уязвимости придёт публично.

## Решение владельца

Решение владельца от 2026-10-15: README, `SECURITY.md` и `CONTRIBUTING.md` на
английском и русском; README называет лицензию Liquibase (ADR-0008).

## Требуется

README: состав, подключение из тега, проверки, документация, лицензия и FSL
Liquibase. `SECURITY.md`: закрытое сообщение через GitHub Security Advisories.
`CONTRIBUTING.md`: заявки по `REQ-ADOPTION-019`, изменения через цикл ядра.

## Критерии приёмки

- Тест первым: оба языка в README, лицензия и FSL названы, `SECURITY.md`
  ведёт в закрытый канал, `CONTRIBUTING.md` ссылается на порядок заявок.

## Откуда пришла задача

Решение владельца открыть проект, 2026-10-15.
