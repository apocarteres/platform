## Назначение репозитория

Репозиторий `platform` содержит общее ядро проектов zavpn и clanlog: библиотеки
Java (Spring Boot starters) и Angular, пакет процессных правил и инструментов
документации. Потребители ядра — отдельные репозитории; ядро не знает об их
предметных областях.

## Требования к ядру

- Ядро не содержит доменных понятий потребителей: ни VPN, ни кланов, ни их сущностей. Расширение выполняется через порты, которые реализует проект-потребитель.
- Ядро не навязывает планировщик и не запускает фоновую работу само. Периодические операции экспортируются как явные команды, а источник вызова выбирает потребитель.
- Несовместимое изменение ядра — новая мажорная версия с описанной миграцией потребителя; см. [версионирование и публикацию](docs/requirements/publishing.md).
- Проза документации на русском языке; английские имена остаются для технологий, идентификаторов, API и команд.
