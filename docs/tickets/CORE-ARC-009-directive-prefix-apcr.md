# Префикс директив ядра — apcr

## Решение владельца

Префикс директив ядра `apo` заменяется на `apcr`, и раз выпуск старший, замена
делается в нём же, а не отдельным несовместимым выпуском. Решение владельца от
2026-09-24.

## Что сделано

`apoModal` → `apcrModal`, `apoModalEscape` → `apcrModalEscape`, класс `ApoModal`
→ `ApcrModal`; новые директивы сразу названы с новым префиксом — `apcrAction`,
`apcrLocal`. Правило `modal-escape`, положения, обязательство и эталонные формы
переведены на новые имена. Прежних имён рядом не оставлено: слоя совместимости
ядро не держит (`REQ-COMPATIBILITY-003`).

## Цена для потребителя

Шаблоны с `apoModal` перестают собираться: сборка со строгой проверкой
отказывает неизвестной привязке. Замена механическая — имена сменились, поведение
нет. Объявлено в документе выпуска разделом «Несовместимые изменения».
