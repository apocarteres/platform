## Назначение репозитория

Репозиторий `platform` содержит общее ядро сервисов: библиотеки Java
(Spring Boot starters) и Angular, пакет процессных правил и инструментов
документации. Потребители ядра — отдельные репозитории; ядро не знает об их
предметных областях и не ограничено заранее известным их перечнем.

## Требования к ядру

- Ядро не содержит доменных понятий потребителей и не упоминает их предметные области. Расширение выполняется через порты, которые реализует проект-потребитель.
- Пакет правил не зависит от стека: правила, цикл выпуска и обязательства общего порядка действуют для проекта на любом языке. Библиотеки для Java и Angular — предложение ядра, а не условие подключения; требование к стеку размечается им и действует, только если проект этот стек объявил.
- Ядро не навязывает планировщик и не запускает фоновую работу само. Периодические операции экспортируются как явные команды, а источник вызова выбирает потребитель.
- Несовместимое изменение ядра — новая мажорная версия с описанной миграцией потребителя; см. [версионирование и публикацию](docs/requirements/publishing.md).
- Проза документации на русском языке; английские имена остаются для технологий, идентификаторов, API и команд.
