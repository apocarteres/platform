# Шаблон выпуска

[Правила](RULES.md) · [Каталог](INDEX.md).

Документы выпуска создаёт и заполняет команда цикла; этот файл описывает,
что в них появляется, и нужен для чтения, а не для копирования руками.

## Открытие

`conventions release open` (для ядра — с ключом `--version X.Y.Z`) создаёт
документ со скелетом: шапка с `status: draft` и `opened-on`, цель, состав
из запланированных обязательств ядра, критерии выхода без отметок,
границы выпуска и раздел результата.

Первый выпуск репозитория с историей открывается командой
`conventions release adopt`: она помечает уже закрытые задачи значением
`before-cycle` и только после этого открывает выпуск.

## Закрытие

`mise run release` выполняет `verify`, получает расписку и закрывает выпуск:

1. состав — задачи, дошедшие до терминального статуса после предыдущего
   выпуска, и обязательства ядра, выполненные в этом;
2. результат — коммит, тег, момент и наборы проверок из расписки;
3. критерии выхода — отмечены с подтверждением из тех же данных;
4. тег выпуска на проверенном коммите;
5. следующий выпуск открыт, обязательства ядра перенесены в него.

## Что делает человек

Пишет задачи и закрывает их. Решает, какой номер у следующего выпуска ядра.
Закрывает обязательство ссылкой на уже сделанную работу
(`conventions release satisfy <обязательство> --ticket <TICKET-ID>`) или
переносит его записью с причиной (`conventions release defer`).
Развёртывает тег выпуска.
