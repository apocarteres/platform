# Пропущенное поле `release` проверка называет несуществующим выпуском

## Проблема

Задача без поля `release` — нарушение `REQ-TICKETS-009`: поле обязательно,
значение — идентификатор выпуска, `unassigned` или `before-cycle`. Проверка
ловит это, но называет не то:

- `docs-check` отвечает «назначенный выпуск не существует», хотя выпуск не
  назначен вовсе, а поля нет;
- `tickets-index` пишет в сводку ссылку `../../releases/undefined.md` и
  этим порождает вторую ошибку, про ссылку.

Ни одна из двух ошибок не называет пропущенное поле и допустимые значения, то
есть выход из отказа (`REQ-QUALITY-005`, `REQ-RELEASE-039`). Исполнитель
читает отказ как «задаче нужен выпуск» и ждёт `release-open`, который
проставляет поле и снимает ошибку. Настоящая причина остаётся незамеченной.

## Подтверждение

Выпуски ядра 11.4.0 и 11.4.1 (2026-09-25): задачи CORE-OPS-100 и CORE-OPS-101
созданы без поля `release`. `docs-check` выдал обе ошибки, ошибки ушли только
после `release-open`, а причину сочли свойством цикла. Код:
`release-model.mjs` (`!release` и неизвестный выпуск идут одной веткой),
`tickets-index.mjs` (`releaseCell` не отличает отсутствующее значение).

## Последствия при сохранении текущего поведения

Задача без поля, закрытая вне цикла, держит проверку документации и сбивает с
толку. Сводка задач получает ссылку в никуда. У потребителя то же самое.

## Решение владельца

Заведено по согласию владельца от 2026-09-25.

## Требуется

1. Отсутствие поля `release` — отдельный отказ: «нет обязательного поля
   `release` (`REQ-TICKETS-009`): укажите `unassigned`, `before-cycle` или
   идентификатор выпуска». Отказ «назначенный выпуск не существует» остаётся
   только для названного, но неизвестного выпуска.
2. Сводка задач не пишет ссылку на `undefined`: задача без поля — отказ
   проверки, а не строка со ссылкой в никуда.

## Критерии приёмки

- Тест первым: задача без `release` даёт отказ, который называет поле и
  значения, и не даёт отказа про несуществующий выпуск; сводка не содержит
  `undefined`. Тесты падают до правки.
- Пробы: слитые обратно ветки и возвращённая ссылка — тесты падают.

## Откуда пришла задача

Разбор выпусков ядра 11.4.0 и 11.4.1, 2026-09-25.
