## Несовместимые изменения

- `platform-persistence` приносит `spring-boot-starter-liquibase` (`REQ-DATA-ACCESS-007`): у службы с модулями ядра и `DataSource` при запуске включается автонастройка Liquibase. Без главного журнала Spring Boot останавливает запуск.

## Миграция

1. Проект на Liquibase: ничего не меняется; свою зависимость `spring-boot-starter-liquibase` можно убрать — версию и сам стартер задаёт ядро.
2. Проект, ещё не перешедший на Liquibase (Flyway или свои переходы): `spring.liquibase.enabled=false` до переезда по обязательству `liquibase-migrations` (срок — 3 выпуска с 13.6.0). Порядок — `docs/runbooks/liquibase-adoption.md`.
3. Главный журнал — по пути `spring.liquibase.change-log` либо по пути Spring Boot по умолчанию `db/changelog/db.changelog-master.yaml`; журналы ядра подключаются в него `include`.
