# Запрос справки открывает выпуск

## Проблема

`conventions release open --help` не печатает справку, а выполняет команду:
создаёт документ выпуска и перестраивает каталог. Запрос о том, как работает
команда, меняет состояние проекта.

Причина шире одной подкоманды. Разбор аргументов выпуска ищет в строке только
известные ключи — `--version`, `--tickets`, `--note`, `--reason`, `--ticket`, —
а всё прочее отбрасывает молча. Поэтому ни `--help`, ни опечатка в имени ключа,
ни лишний аргумент не отвергаются нигде в команде выпуска.

`REQ-RELEASE-028` требует ровно обратного, но только от расписки: она отвергает
неизвестный аргумент, файла при этом не создаёт, а `--help` печатает справку.
Требование написано для одной команды, хотя обосновано свойством всех.

## Чем подтверждено

Заявка потребителя [issue #12](https://github.com/apocarteres/platform/issues/12),
ядро 1.18.0, задача потребителя `ZAVPN-OPS-046`. Воспроизведено на эталонном
потребителе:

```
release open --help -> Открыт выпуск RELEASE-2026-09-11
новых документов выпуска: [ 'RELEASE-2026-09-11.md' ]
```

## Что сделано

Решение владельца 2026-09-13: свойство обобщено с расписки на все команды пакета
и записано в `REQ-RELEASE-028`. `--help` печатает справку своей команды и
состояния не меняет; неизвестный ключ, ключ без значения и лишний аргумент
отвергаются с названием аргумента и кодом возврата 2; при отказе не создаётся ни
файла.

Разбор аргументов сведён в `lib/cli/arguments.mjs` и один на все команды: ветка
команды получает разобранные значения, а не ищет свои ключи в строке сама.
Поэтому новая подкоманда наследует свойство, а не забывает о нём. Справка у
каждой подкоманды своя и называет её ключи; общий перечень печатается без
аргументов и по `--help`.

Закреплено четырьмя проверками: справка печатается и документа не создаёт, отказ
не создаёт документа, отвергаются ключ без значения, лишний аргумент, чужая
подкоманда и чужая команда, а знакомые аргументы открывают выпуск по-прежнему.
Различающая сила проверена возвратом прежнего поведения — две проверки отказали.
