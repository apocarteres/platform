# Security policy

## English

Please do not report vulnerabilities in public issues. Report them privately
through GitHub: <https://github.com/apocarteres/platform/security/advisories/new>.

Include the core version (release tag), the affected module, how to reproduce
the problem, and its impact. You will get an answer before the next core
release is closed. A fix is released as a patch version and announced in the
release document after it is available.

Only the latest release is supported. Projects adopt fixes by moving to a
newer release tag.

## Русский

Об уязвимости не сообщайте публичной заявкой. Сообщайте закрыто через GitHub:
<https://github.com/apocarteres/platform/security/advisories/new>.

Укажите версию ядра (тег выпуска), затронутый модуль, как воспроизвести и чем
это грозит. Ответ придёт до закрытия следующего выпуска ядра. Исправление
выходит patch-версией и описывается в документе выпуска, когда оно уже
доступно.

Поддерживается только последний выпуск: проект получает исправление,
переходя на более новый тег.
