# Версия платформы приложений задавалась дважды и разошлась

## Проблема

Ядро управляло версиями Spring Boot собственным свойством, а сервис-потребитель
наследовался напрямую от `spring-boot-starter-parent` со своей версией. Одно и
то же решение принималось в двух местах, и ничто их не сверяло.

## Подтверждение

Замер 2026-09-07: `platform-parent` объявлял `spring-boot.version` **4.0.4**,
а `backend/pom.xml` потребителя — `spring-boot-starter-parent` **4.0.8**.
Расхождение прожило в репозиториях незамеченным: библиотеки ядра собирались и
проверялись против версии, которой у потребителя нет.

Кроме версии, потребитель держал у себя то, что общее для любого сервиса на
ядре: профиль интеграционных тестов с `**/*IT.java` (28 строк), объявление
сборочного плагина исполняемого артефакта, уровень языка и кодировку,
импорт `platform-bom`.

## Последствия при сохранении текущего поведения

Обновление платформы приложений требует правки в каждом репозитории, а
несовпадение версий проявляется не отказом сборки, а разным поведением
библиотеки ядра у себя и у потребителя. Профиль интеграционных тестов,
требуемый `REQ-QUALITY-003`, существует копией в каждом сервисе.

## Ожидаемый результат

Сервис наследует родительский POM ядра. Версия платформы приложений живёт в
одном свойстве всего решения; профиль интеграционных тестов, сборка
исполняемого артефакта, фильтрация файлов настроек и версии сборочных плагинов
приходят наследованием.

## Границы

Родитель для сервисов отделён от родителя библиотек ядра: библиотеке не нужны
ни сборка исполняемого артефакта, ни фильтрация настроек, ни профиль
интеграционных тестов. `platform-service-parent` наследуется от
`platform-parent`, поэтому версия платформы приложений остаётся одна и та же
для ядра и для сервиса, а не повторяется через `spring-boot-starter-parent`.

## Критерии приёмки

- [x] `platform-service-parent` опубликован ядром: импорт `platform-bom`, фильтрация `application*` с ограничителем `@`, версии `maven-resources-plugin`, `maven-failsafe-plugin` и сборочного плагина Spring Boot, профиль `integration-tests` (`REQ-QUALITY-003`)
- [x] Версия платформы приложений задаётся одним свойством `spring-boot.version` в `platform-parent`; ядро поднято до 4.0.8, то есть до версии, которая работает в проде потребителя
- [x] Требование [REQ-BUILD-011](../../requirements/build.md#REQ-BUILD-011) объявляет наследование родительского POM ядра обязательным
- [x] Потребитель переведён на родителя, `verify` пройден на этом состоянии
