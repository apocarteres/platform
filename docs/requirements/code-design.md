# Проектирование кода

[Карта требований](../REQUIREMENTS.md)

Документ нормативен для платформы и для всех проектов, подключивших пакет `@apocarteres/project-conventions`. Он не копируется в репозитории потребителей: пакет доставляет этот файл вместе с собой.

## Деньги и величины

1. <a id="REQ-CODE-DESIGN-001"></a> **REQ-CODE-DESIGN-001** — Деньги и балансы хранятся и вычисляются только через десятичный тип с фиксированной точностью. Двоичные типы с плавающей точкой для них запрещены.

## Полиморфизм вместо ветвлений

2. <a id="REQ-CODE-DESIGN-002"></a> **REQ-CODE-DESIGN-002** — Для расширяемой логики предпочитаются интерфейсы и отдельные реализации, а не длинные каскады `if/else` и `match`, если полиморфная модель делает код понятнее и не усложняет архитектуру.

## Операции чтения

3. <a id="REQ-CODE-DESIGN-003"></a> **REQ-CODE-DESIGN-003** — Операции и методы класса `list`, `find`, `fetch`, `get`, `retrieve`, `search`, `view`, `show`, `load` и аналогичные им не имеют побочных эффектов ни в каком виде. Они не меняют базу, runtime и desired state, кеши с бизнес-смыслом, статусы сущностей, балансы, журналы, метрики жизненного цикла, внешние системы и не публикуют события.
4. <a id="REQ-CODE-DESIGN-004"></a> **REQ-CODE-DESIGN-004** — Если для корректности нужен переход состояния, обновление, сверка, материализация или другая мутация, она оформляется отдельной командной операцией с явным названием, транзакционными границами и тестами.

## Ответы API

5. <a id="REQ-CODE-DESIGN-005"></a> **REQ-CODE-DESIGN-005** — Ответ API воспринимается как неизменяемый снимок. Использовать DTO ответа, списки из него или поля view-model как мутабельное рабочее состояние, очередь расходования или скрытое хранилище запрещено.
6. <a id="REQ-CODE-DESIGN-006"></a> **REQ-CODE-DESIGN-006** — Если нужно состояние, очередь или кеш, вводится явная доменная модель либо отдельное состояние клиента с понятной ответственностью.

## Представление данных

7. <a id="REQ-CODE-DESIGN-007"></a> **REQ-CODE-DESIGN-007** — Даты и время в интерфейсе показываются локализованно, а не строками формата обмена данными.
